---
id: review-the-diff
description: Review a branch's changes and report problems, without changing code
on_finish: none
---

Review the changes on the current branch compared to the main branch.

Look for bugs, missing tests, unclear naming and anything that could break
existing behavior. Don't change any code: write what you find as a list, most
serious first, each with the file and line and a suggested fix.

Done when: you have written the list, or said clearly that you found nothing.
